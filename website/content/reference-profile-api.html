The five @meantjs packages are plain ES modules with hand-written TypeScript declarations (src/*.d.mts), one per exported entry. Every signature on this page is quoted verbatim from those files, and the build checks each quote against the file it names. The guides show the same functions in use: Validate and resolve, Parse and display values, Consent messages, Agent tools and Settle an unknown outcome.

Install

npm install @meantjs/profile@0.5.0 @meantjs/format@0.5.0 \
  @meantjs/consent@0.5.0 @meantjs/tools@0.5.0 @meantjs/reconcile@0.5.0

Each name links to its source under profile/packages/; @meantjs/profile is packages/resolver.

fact 0.5.0 was published to npm on 2026-10-30, all five under latest and each with signed provenance (the npm registry, read 2026-10-30). It adds pins and x402 payments (spec §15.4, §15.9, D-058, experimental): the tag fixed in @meantjs/profile, beside the contract profiles usdc, usdc-base-sepolia and x402-exact-permit2, and E_FIXED in evmConsent and eip712Consent. @meantjs/format did not change in 0.5.0: its changelog says "No changes in this package", and only its version moved. @meantjs/tools and @meantjs/reconcile changed only a spec reference in their README files (D-057), with no change in behavior. Each package's CHANGELOG.md lists what changed; 0.4.0 (2026-10-30) added what a call grants (spec §5.3, D-056) and @meantjs/consent/terms, and 0.3.0 (2026-10-29) EIP-712 typed messages (spec §15.9, D-055, experimental).

The five packages release together under one version and pin each other exactly ("0.4.0", not "^0.4.0"), so an install never mixes versions that were not tested together. A release bumps all five even when only one changed. While the major is 0 the minor is the breaking digit, and any change to text the packages generate (consent messages, SNS renderings, tool names, descriptions, input schemas) is a breaking change. The procedure is profile/docs/releasing.md.

All entries are ES modules only. An EVM resolved form ("chain": "evm") is experimental, spec §15: see EVM contracts.

@meantjs/profile

Validates profiles, matches packs to a service, merges layers and emits the resolved form. Also the candid-profile command (The candid-profile command).

import { readFileSync } from "node:fs";

const validateSchema = await createSchemaValidator();

@meantjs/profile/schema.json and @meantjs/profile/packs/*

JSON documents, not modules: ./schema.json is the package's copy of spec/profile-v0.schema.json, and ./packs/* its copies of the nine standard files of profile/packs/: the packs icrc1.profile.json, icrc2.profile.json, erc20.profile.json and erc2612.profile.json, and the EVM contract profiles permit2.profile.json, dai-permit.profile.json, usdc.profile.json, usdc-base-sepolia.profile.json and x402-exact-permit2.profile.json (experimental, §15.9). A contract profile is never tried as a pack: pass it in profiles. Import them with an import attribute, and pass them as documents: 

import schema from "@meantjs/profile/schema.json" with { type: "json" };          // copy of spec/profile-v0.schema.json
import icrc1 from "@meantjs/profile/packs/icrc1.profile.json" with { type: "json" };
const validateSchema = await createSchemaValidator(schema);                            // a document, not a path
const r = await resolveService({ did, validateSchema, packs: [{ doc: icrc1 }] });

The packs and their annotations are listed on Standard packs.

@meantjs/consent

ICRC-21 consent messages for any method, from a resolved form and the Candid-encoded argument bytes; the text an SNS proposal's validator returns; experimental, consent text and ERC-7730 files for EVM calls and EIP-712 signing requests; and, since 0.4.0, what a request grants and the check of that grant against terms the person confirmed (/terms). No network code.

One tool per query method, one prepare_<method> per update method, and commit. An EVM resolved form is refused: EVM tools are a later phase.

@meantjs/reconcile

Consumer rule 1 without a transport: after an unknown outcome, before any new attempt, is the original in the ledger's ICRC-3 history? The caller reads the blocks (certified, archives followed) and passes them in.
