| OQ-1 | **A public custom section, `icp:public candid:profile`, read with `candid:service` in one certified `read_state`** (spec §8.1, D-048). The section holds the profile as UTF-8 JSON, an `author` canister profile bound to the interface the canister serves; a consumer binds it against that `candid:service` (§7). A path the certificate shows absent means nothing is served; a path it neither holds nor rules out is an error, never absent. A query method is not proposed: its reply is not certified. Yes, metadata read through `read_state` is certified. | 2026-10-27 | [IC interface specification](https://docs.internetcomputer.org/references/ic-interface-spec/) (the section is at `/canister/<id>/metadata/<name>`; a private one only for controllers) and its HTTPS interface (`read_state` returns a certificate of the state); [resource limits](https://docs.internetcomputer.org/references/resource-limits/) (16 `icp:` sections, 1 MiB). **Observed** (`packages/kit/pocketic/test/served.test.mjs`, PocketIC 16.0.0): a module given the section by `candid-profile-kit embed` serves it byte for byte through `@icp-sdk/core` 6.1.0 `readState`, with the certificate verified; a canister without it shows the path absent; a private section is refused to a non-controller. Behrad's go on 2026-10-27 (proposal `proposals/w6-adoption.md` item 4). |
| OQ-15 | **Yes, the whole prompt.** `prompt_eval_count` is the full prompt token count on every turn, cached or not: Ollama 0.40.2 with `gemma4:e2b`, `e4b` and `12b-mlx`, `think:false`, `num_ctx` 32768, a three-turn conversation run cold, warm and on a fully cached repeat (14 to 48 ms) gave 2740, 5008 and 7296 tokens per turn each time (12b-mlx 2744 on the first). | OQ-4 | An occurrence `path` is a sequence of steps from `type:<Decl>` or `actor.methods[i]` (`actor.service.methods[i]` for a service class), then `.function.args[j]` / `.function.results[j]`, then any number of `.type`, `.fields[k]` (canonical id order), `.inner` (the element of an `opt` or `vec`) and `.args[j]` / `.results[j]` inside func-typed values. `field_labels` entries also carry the Contract container and field id. To map a doc on an inline actor field to a method address: match the path's method prefix to `methods[].path`, let the next step pick `(j)` or `->(j)`, then walk the Contract writing `.label` per field step, nothing for `opt`, `[]` for `vec`.
